# Gestion des Tâches

Application console en Python pour gérer des tâches quotidiennes.

## Fonctionnalités
- 1. Ajouter une tâche (refuse la saisie vide).
- 2. Afficher les tâches (avec numéro et message si liste vide).
- 3. Rechercher une tâche (par mot-clé).
- 0. Quitter l'application.

## Exécution
1. Ouvrir le dossier dans Visual Studio Code.
2. Ouvrir le fichier main.py.
3. Cliquer sur le bouton « Run Python File » en haut à droite.
